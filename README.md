# esviritu_benchmarks

Project for running and analyzing EsViritu benchmarks

# scripts

Bash srcipts for running tools on CMMR HPC: 
 - `scripts/runners/`

Python scripts for parsing tool output files:
 - `scripts/mock_benchmark/`
 - `scripts/negative/`
 - `scripts/positive/`
 - `scripts/reconstructions/`
 - `scripts/scaling/`


# notebooks/

R Notebooks for statistical analysis and plotting of processed tool outputs. 

Uses data in `data/` (see below).

# stats/

Tabular files summarizing stats from analysis notebooks.
